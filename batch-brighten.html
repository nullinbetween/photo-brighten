Choose a folder → adjust with a live preview → one click writes brighten/ inside it. Your photos are processed in this browser and never uploaded. JPG/JPEG/PNG only; the output keeps each file’s format (PNG keeps transparency); your originals are never modified.
Drop a photo folder (or photo files) here
⚠ This browser cannot write back into a folder (Safari, Firefox and others). Click above to choose photo files (multi-select works) or drop them in; each brightened photo is handed to the browser as a download (normally into your Downloads folder). The browser may ask once whether to allow multiple downloads. The page cannot see whether each download was saved, so check the folder afterwards; how same-name files are handled is up to the browser (usually a number is added).
